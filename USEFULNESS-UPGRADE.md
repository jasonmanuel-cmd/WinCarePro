# Bounded usefulness upgrade

## Scope and baseline
Preserve the current uncommitted completion candidate (191 tests reported in FINISH-UP-RESULTS.md). Sole writer for this pass; no reset, dependency upgrade, commit, installer or publication. Existing dashboard has RAM/storage cards, cleanup preview and synchronous refresh, but no prioritized guidance or user-controlled sanitized diagnostic export. Existing EnvironmentReport is internal startup diagnostics, includes identifying paths, and must NOT be reused as an export payload.

## Three additions / acceptance criteria
1. **Evidence-based next steps:** a pure typed snapshot/guidance service reuses existing RAM, system-drive and two privacy-setting readers. Validate percentages/capacity; unknown is not zero/healthy. Timestamp snapshots, label stale after one minute and suppress stale recommendations. Stable ordering: low disk headroom, high RAM usage, optional privacy review, missing evidence. Link suggestions to existing Disk Analyzer, App Remover and Privacy Shield panels; no new maintenance engine. Explain that one observation is not a diagnosis and thresholds are heuristics, not promised speedups. Keep existing score unchanged and explicitly identify its limits.
   - Fixtures: disk/RAM priority and stable ties, healthy/empty, null/invalid values, stale/future/missing timestamps, privacy unknown/off distinction, navigation.
2. **Read-only rescan:** replace the existing refresh command with a background snapshot scan with busy/cancel/error/status feedback. Only one active scan; cancellation discards late results and retains previous snapshot. Check cancellation between native queries; cannot interrupt a blocked native query. UI updates return to dispatcher. Initial dashboard load requests the same scan. Do not scan temp files, run network probes, or mutate settings.
   - Fixtures: pre-cancel, mid-scan cancel, overlapping calls, failed reader, preservation of previous snapshot; safe-mode composition inspected before execution.
3. **Local diagnostic export:** preview an immutable allowlisted report in the dashboard; disclose included measurements/time and omitted identities/paths/commands/logs. Save only after explicit Save As dialog; no automatic upload or export. Export excludes machine/user names, drive labels/paths, process lists/command lines, raw error messages, credentials and internal EnvironmentReport. Saving the exact preview gives a visible success/failure; cancel writes nothing.
   - Fixtures: payload allowlist/redaction by construction, preview immutability, local fixture write/readback, denied write and cancelled dialog. Never export host private data for tests.

## UI contract

Native buttons with explicit automation names, visible keyboard focus, disabled/busy states and status live-region metadata. Empty/loading/unknown/cancel/error states must be readable. No broad visual redesign or new dependency. Capture existing eight views plus changed dashboard fixture states and export preview; screenshots prove only those rendered states, not native screen-reader/modal/DPI coverage.
