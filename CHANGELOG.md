# Changelog

All notable changes to WinCare Pro are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); this project uses
semantic versioning.

## [Unreleased]

### Added

- `Services/EnvironmentReport.cs` — writes `environment.txt` (OS, elevation,
  DPI mode, tool presence) so support tickets don't need to ask for it one by
  one.
- `Services/UpdateChecker.cs` — opt-in, user-initiated version check. This is
  the only network code path; it never runs automatically and is documented in
  `PRIVACY.md`.
- +3 `UpdateCheckerTests` → 116 total.

### Changed

- `App.xaml.cs` now writes `environment.txt` on every launch and the crash
  message points at both files.

### Security / honesty

- The "no outbound connections" promise in `PRIVACY.md`/`EULA.md` now has one
  explicit, user-triggered exception: the manual update check.
- Code signing remains the one blocker that cannot be fixed in code — an EV/OV
  certificate is still required before public distribution.

## [1.0.0] — 2026-10-05

First public build. Productionized from the internal prototype.

### Added

- **Application icon.** Branded teal bolt, multi-resolution (.ico generated by
  `Tools/MakeIcon`, per-size PNGs committed under `Assets/`).
- **App manifest.** PerMonitorV2 DPI awareness, `asInvoker` execution level,
  long-path support, Windows 10/11 compatibility GUIDs.
- **Assembly metadata.** Company, copyright, version, title, and description
  populate the exe's file properties and Add/Remove Programs.
- **Single instance.** A second launch focuses the existing window instead of
  opening a parallel copy that polls the same system and writes the same
  history file. Named mutex survives a force-kill (abandoned mutex is taken
  over, not blocked).
- **Crash hardening.** Exception handlers for the dispatcher, the AppDomain,
  and unobserved task exceptions; crash log rotates at 2 MB into
  `crash.previous.log` instead of growing forever.
- **MSI installer** (`installer/WinCare.wxs`, WiX v5): per-user, no elevation,
  MajorUpgrade handling, Start Menu shortcut, Add/Remove Programs entry,
  history preserved across uninstall. Build script
  (`build-installer.ps1`) gates on tests and verifies the MSI payload with a
  real administrative install.
- **Signing script** (`sign-release.ps1`) and full release docs
  (`RELEASE.md`), license (`LICENSE.md`), privacy policy (`PRIVACY.md`), and
  EULA (`EULA.md`).
- **Tests.** +3 single-instance tests → 113 total.

### Fixed

- Power-plan switcher never marked its own active plan (GUID format bug —
  `ToString("B")` vs bare `"D"`). Covered by 14 regression tests that go red
  when the bug is reintroduced.
- Hover style coverage is now reported for all 11 clickable cards.

### Known limitations (honest, not hidden)

- WPF single-file publish still emits native sidecar DLLs; the installer now
  ships all of them. The exe alone will not run.
- Real hover frames cannot be captured in this environment or headless CI —
  coverage is verified, appearance is not.
- Only Windows 10/11 x64 is supported. No telemetry, no network calls by
  design; see PRIVACY.md.
